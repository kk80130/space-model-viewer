# 空间预览台

在线使用：https://kk80130.github.io/space-model-viewer/

打开网页，点击顶部的「导入模型」，选择自己电脑上的 `.glb` 文件。也可以把 GLB 拖到三维画布。模型在当前浏览器读取，不上传保存；刷新后需要重新导入。

支持旋转、缩放、标准视角、材质预览、对象选择与隐藏；模型内含的动画可在右侧播放。顶部可切换餐厅拆解演示视频，侧栏可恢复餐厅示例。

模型要求：glTF 2.0 二进制 GLB，贴图打包在文件内部。当前版本不包含 Draco、Meshopt、KTX2 解码器，导出时请关闭这些压缩。Blender 工程、FBX、OBJ 请先转换成 GLB。较大的模型需要更长加载时间和更多显存。

建议使用电脑上的新版 Edge 或 Chrome。第三方 Three.js 的许可见 `vendor/LICENSE`。
